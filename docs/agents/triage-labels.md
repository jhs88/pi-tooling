# Triage labels

Each canonical skill role uses the same label name in this repository's GitHub Issues.

| Skill role        | GitHub label      | Meaning                                        |
| ----------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Needs maintainer evaluation                    |
| `needs-info`      | `needs-info`      | Waiting for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent         |
| `ready-for-human` | `ready-for-human` | Requires human implementation                  |
| `wontfix`         | `wontfix`         | Will not be actioned                           |

When a skill names a triage role, use the corresponding GitHub label.
