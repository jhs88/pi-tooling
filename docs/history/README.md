# Historical planning artifacts

This directory preserves the resolved local-Markdown planning, research, and prototype records that originally lived in a Pi configuration repository while `pi-tooling` was developed there.

These files are evidence, not active tickets. Their paths, statuses, assumptions, and “not yet specified” sections reflect the state at the time they were written and may now be superseded.

Use Hermes Kanban board `pi-tooling` for all current work, dependencies, decisions, and audit history. Do not add new issue files here.
